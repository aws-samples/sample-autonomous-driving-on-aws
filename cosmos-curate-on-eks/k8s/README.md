# k8s

Kubernetes-side pieces used by the scripts. The Curator itself is installed from the upstream
[cosmos-curator Helm chart](https://github.com/nvidia-cosmos/cosmos-curate/tree/main/charts/cosmos-curator)
by `scripts/setup_curator_pod.sh`, which also generates the Helm values for the selected node option.

| File | Purpose |
|---|---|
| `run_split.sh` | `k8s/run_split.sh <region> <dataset>` submits split + Cosmos-Embed1 embedding + Bedrock caption as a Ray job on `s3://<bucket>/inputs/<dataset>/` and prints the output prefix |
| `post-renderer.sh` | Helm post-renderer that sets the StatefulSet to `podManagementPolicy: OrderedReady`, so pod-0 (the Ray head) is created first and takes the reserved on-demand node in option `b` |
| `prompts/caption_prompt.txt` | Example caption prompt; pass your own with `--captioning-prompt-text` |

Placement summary (generated by `setup_curator_pod.sh`):

| Option | Curator tolerations | Node affinity |
|---|---|---|
| `a` (4 on-demand) | none | none |
| `b` (3 Spot + 1 on-demand) | `spot-instance:PreferNoSchedule`, `dedicated=curator:NoSchedule` | prefer `node-type=on-demand` |
| `c` (4 Spot) | `spot-instance:PreferNoSchedule` | none |

All options spread Curator pods one per node (pod anti-affinity) and run the caption proxy's two
replicas on different nodes.
